          Computing at scale

          Brandes' algorithm

          Exact betweenness centrality for every node in O(nm) time. One breadth-first search per source counts shortest paths, and one backward sweep hands each node its share.

          Betweenness centrality asks, for every node, what fraction of the shortest paths between other pairs pass through it. Summing over all pairs naively costs O(n3)O(n^3)O(n3) or more. In 2001 Ulrik Brandes showed how to compute every node’s betweenness in O(nm)O(nm)O(nm) time on unweighted graphs, by processing one source at a time and accumulating each node’s share in a single backward sweep. Every major graph library implements his algorithm, and every approximate method for large graphs builds on it.

          Counting shortest paths

          From a source sss, a breadth-first search finds each node’s distance d(s,v)d(s, v)d(s,v) and the number of shortest paths σsv\sigma_{sv}σsv​ from sss to vvv. Paths are counted along the way: σss=1\sigma_{ss} = 1σss​=1, and for every node vvv,

          σsv=∑u∈preds(v)σsu,\sigma_{sv} = \sum_{u \in \text{pred}_s(v)} \sigma_{su},σsv​=u∈preds​(v)∑​σsu​,

          where preds(v)\text{pred}_s(v)preds​(v) holds the nodes uuu with an arc u→vu \to vu→v and d(s,u)+1=d(s,v)d(s, u) + 1 = d(s, v)d(s,u)+1=d(s,v). The search also records the order in which nodes are reached.

          Accumulating dependencies

          The dependency of sss on vvv is the share of shortest paths from sss, to all targets, that pass through vvv:

          δs(v)=∑t≠s,vσst(v)σst.\delta_s(v) = \sum_{t \ne s, v} \frac{\sigma_{st}(v)}{\sigma_{st}} .δs​(v)=t=s,v∑​σst​σst​(v)​.

          Worked example

          Take $s = $ E in the running example. Breadth-first search reaches C, D and F at distance 1, A and G at distance 2, and B at distance 3. A has two shortest paths, through C and through D, so σEA=2\sigma_{EA} = 2σEA​=2; B inherits them, σEB=2\sigma_{EB} = 2σEB​=2; every other node has one.

          Sweeping back from the farthest node:

          • B and G end no one else’s path: δ=0\delta = 0δ=0.
          • A passes on B’s paths: δ(A)=22(1+0)=1\delta(A) = \frac{2}{2}(1 + 0) = 1δ(A)=22​(1+0)=1.
          • D carries half of A’s paths: δ(D)=12(1+1)=1\delta(D) = \frac{1}{2}(1 + 1) = 1δ(D)=21​(1+1)=1.
          • C carries the other half of A’s paths and all of G’s: δ(C)=12(1+1)+11(1+0)=2\delta(C) = \frac{1}{2}(1 + 1) + \frac{1}{1}(1 + 0) = 2δ(C)=21​(1+1)+11​(1+0)=2.

          Source E thus gives C 2, A 1 and D 1. Repeating from every source and summing gives the final betweenness of the running example: C 6, A 3, D 1, and 0 for the rest. The lab on the Betweenness centrality page runs exactly this code.

          Cost

          Each source costs one BFS, O(n+m)O(n + m)O(n+m), and one backward sweep over the same arcs, so all sources cost O(n(n+m))O(n(n + m))O(n(n+m)), written O(nm)O(nm)O(nm) for connected graphs. Memory is O(n+m)O(n + m)O(n+m): one source’s distances, path counts, predecessor lists and dependencies at a time, plus the betweenness totals. On weighted graphs, Dijkstra’s algorithm replaces BFS and the cost becomes O(nm+n2log⁡n)O(nm + n^2 \log n)O(nm+n2logn).

          Sources are independent, so the algorithm parallelises perfectly across sources: each thread processes its own sources and keeps its own totals, summed at the end.

          Too slow for the web, so sample

          O(nm)O(nm)O(nm) is quadratic in practice. For Common Crawl’s domain graph it means about 3×10173 \times 10^{17}3×1017 arc visits. The standard remedy samples:

          • Random sources. Run the algorithm from kkk random sources and multiply the totals by n/kn/kn/k (Brandes and Pich, 2007). The estimate is unbiased, and a few thousand sources rank the top nodes well.
          • Adaptive sampling for one node. Bader and colleagues sample sources until the target node’s accumulated dependency passes a threshold, which estimates high-betweenness nodes with few samples.
          • Random shortest paths. Riondato and Kornaropoulos sample one random shortest path at a time and bound the sample size with VC-dimension arguments, giving an additive error guarantee for all nodes at once. KADABRA (Borassi and Natale, 2016) samples paths with a balanced bidirectional search and adaptive stopping, which made betweenness estimates on graphs with billions of arcs practical.
